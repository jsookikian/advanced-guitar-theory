# Advanced Guitar Theory

Short, interactive fretboard lessons for players who already know their pentatonics. A lesson-style site: a catalog at the root, one folder per lesson.

| Lesson | Folder |
|---|---|
| Dominant Pentatonics and Half Diminished Chords (the "9 approach") | `lessons/dominant-pentatonics/` |

## Layout

| Path | What it is |
|---|---|
| `index.html` | The catalog. Generated by `build.mjs` from every `lessons/*/lesson.json`. Do not edit by hand. |
| `lessons/<id>/` | One lesson's served files: `index.html` and `app.js` (generated), `lesson.json` (title, summary, level, order), and the lesson's own `README.md` / `CONTEXT.md`. |
| `src/lessons/<id>/` | The lesson's React source: `main.tsx` (entry, default-exports the App) and `lesson.tsx`. |
| `src/shared/` | Code shared by lessons: `audio.ts` (tap-to-hear notes, arpeggio and strum playback with stop) and `grok-canvas-shim.ts`, which re-exports React hooks under the `grok/canvas` import the first lesson was written against. |
| `build.mjs` | Builds every lesson and the catalog. |
| `sounds/` | Recorded guitar samples (FluidR3 GM, CC BY 3.0), played by `src/shared/audio.ts`. See `sounds/README.md`. |
| `tests/`, `renders/`, `source-material/` | Puppeteer checks, screenshots and the original sheet for lesson 1 (see its README). |
| `forma.yaml`, `context/SPACE.md` | The Forma space declaration and its description. |

## Commands

```bash
npm install
npm run build        # builds all lessons and the catalog; commit the output
npm run dev          # same, unminified
npm run serve        # static server on http://localhost:8000
npm run typecheck
```

Run the browser checks from `tests/` (see `lessons/dominant-pentatonics/README.md`).

## Adding a lesson

1. Create `src/lessons/<id>/main.tsx` (mount your App into `#root`, as lesson 1 does) and its component.
2. Create `lessons/<id>/lesson.json` with `title`, `summary`, `level` and `order`.
3. `npm run build`. The build writes `lessons/<id>/index.html` and `app.js` and adds the lesson to the catalog.
4. Commit the source and the generated files together: a Forma Managed space serves the files exactly as committed, there is no build step on the server.

House rules every lesson follows (from lesson 1): white paper look, light only, no layout shift between steps, copy above the board, every root a red R, 36px controls, no sideways page scroll at 320px.

## Forma

This repo is a Forma Managed web app space. The platform serves it flat by path: the catalog at `/`, a lesson at `/lessons/<id>/index.html`. Our organization allows only `sqsp` GitHub repositories as a deploy source, so the space is bound by files upload rather than to this repo: after changes, from the repo root, run `forma redeploy` (the CLI needs `forma login --server https://tryforma.com` once). Nothing is deployed from a push.
